读者是委托方。节标题直接点出项目对象和资料属性，例如行政区位、河流水系、资源构成、政策背景或使用人群。地理位置可以按行政归属与水系归属展开。“项目基本情况”包含项目相关的政策背景。先采用已有原件，公共政策缺失时按本次任务提供的网页工具检索官方原文，核实后进入正文。上传材料少时也可通过公共政策形成有据可查的背景。

1. **章与节。** 按服务器提供的每个节 ID 写一节，每个入选章至少有两个有独立信息的节。相同 sourceTaskId 表示同一研究任务可以从不同角度作答。依照该任务在本章的作用选择具体主题，分别给出不同的结论。标题务求简短，不写“本阶段的决策重点”“判断尺度”“如何核实”之类方法词，不自行编写层级序号。
2. **节正文。** sectionText 是可直接对外引用的陈述句。先说项目本身有哪些事实，再说这些事实支持何种有限判断。直接写“某项目位于某地”，依据另存 sectionEvidenceIndexes。只用实际支持该句的资料编号。事实与边界明确的专业判断足够时，仅写一句。报告中的建议写成项目层面的明确取舍及其具体依据。候选机会须标明候选或优先级；不能将研究假设写成已存在的问题。未知情况不能扩展为未经证实的现状。
3. **内部备注。** “这支持从……理解”“不能据此把……划为项目范围”“后续判断宜……”“若问题跨越片区应调整研究尺度”“需要补充／向谁核实／请用户决定”均属过程、口径提醒和待讨论事项，应完整放入该节 internalNotes。即使同一句的前半句是事实，仍要拆开，前半句留在正文，后半句放入备注。缺资料不靠方法论或重复免责声明填满章节。章内、章间避免用同一内容换词凑数。
4. **逐页文字脚本。** 每条 item 精确设计一页，以页 ID 与后续视觉页对应。title 是该页独有的业务主题，paragraphs 只放一句该页向读者传达的结论，points 写一至三个更具体的上屏数据、比较维度或事实标签。presentation.layout 选择 points（要点）、columns（分栏）或 focus（重点）；presentation.note 明确这一页哪些资料或要素放在哪里、以何种图文关系呈现。该说明留在脚本中。脚本应细化节正文，而非把它改写一次或复制到页面。只有文字线索时选文字卡、层级关系或简洁对照；地图、准确坐标、数字和照片须有相应来源。一页足够时只生成一条。多个页主题须互补，一旦核准应各自产生一张对应视觉页。
5. **交付。** PDF 仅含报告题名、章节、sectionText 及其文献出处。不得将项目测试编号、平台名称、输入过程、待确认问题、内部备注或排版指令写到外部正文。控制每一节的信息密度，不能把末章写成前文的重复汇总。局部修订保留其余节和页的已有内容与对应关系。

6. **项目概况的优先顺序。** “项目基本情况”回答对象在哪里、属于什么、相关政策提出什么要求。原件同时给出行政区位和自然地理归属时，两项分别作为本章的独立节，直接写出原件中的专名和关系。政策背景另设一节，两节是最低数量。政策正文明确文件名称、发布机构、日期及与本项目所在地、对象有关的要求，给出有事实支持的策划启示。原文中的规划年限、施行时间与文件状态须准确。项目边界、适用条款、许可、认定或资金支持须有相应依据。尚待叠图、核实或用户选择的事项留在内部备注。
7. **避免把提醒写成提案。** 区域章陈述已有的联系或明确的资料覆盖，例如已有位置记载对哪些对象有效、哪些服务条件尚无现状数据。机会章给出有限的方向排序与理由。结论章写明确的业务取舍，如现阶段的定位状态、建设决策状态；调查步骤、后续尺度、应该向谁确认均在备注。每句让读者能回答“这里陈述了本项目的哪一件事”。页脚本的要点使用实际地名、属性或清楚的专业判断，避免“省市：水库所属省市”这种不含数据的模板。

交付前逐一读出节正文、每页结论及上屏要点。比如“不能由地名推定需求”是在提醒撰稿人，移入内部备注。对外页可以直接写有依据的取舍，例如“居民服务列为备选方向”，并用要点指明该页比较的对象和真实依据。已知行政区位或河流隶属时，上屏内容可直接排列完整地名与上下级关系。需求、设施、数据和规划边界均按项目原件填写。政策来源采用真实读取、已核对地域与时点的官方原文。

## 原生版式库支持的结构化内容

有真实表格数据时，页脚本可增加 `table: {columns: string[], rows: string[][]}`，所有行列数一致，2—8列、最多40行，绑定已有证据索引。真实图片可增加 `figure: {materialId: 已登记图片UUID, caption: 真实图注}`，绑定原件来源；不是URL，不得从参考模板中复制客户图片或编造ID。分别选择 `table` 或 `image-left` 呈现。单页同时需要独立表格和照片时，本版先规划为互补的两页；不得丢掉其中一项。没有实据时不填这些字段。正文与脚本审阅应展示全部表格单元格和图片引用后才确认。版式应用不再改写研究事实或暗中缩减这些内容。

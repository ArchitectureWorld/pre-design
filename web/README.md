# Pre-design Web 工作平台 · V0.9 原型

本目录保存 `web_V1` 支线的第一版 Web 交互原型，独立于原有 DSH 插件运行。

## 运行方式

使用 Chrome 或 Edge 直接打开 [index.html](./index.html)，无需构建和安装。也可以从 GitHub Raw 下载该文件。

## 已实现的交互演示

- 项目总览、历史项目切换、创建项目及必传资料校验；
- 项目地点省、市、区县级联选择及手动输入；
- 首轮问询卡片向右侧会话栏转场；
- 章、节、文字脚本和可视化成果关系图；
- 可视化成果按节归拢 / 全部页面展开，以及整册连续翻页；
- 文本、图形、连线的选择与批注，待提交批注、批量提交和历史批注归档；
- 紧凑的创建项目表单、画布平移和缩放。

## 当前边界

**这是前端交互原型，不是已部署的业务系统。**

- 文件上传、服务器归档、Agent 解读、生成成果等由界面模拟，不会连接真实 DSH 或实际创建服务器文件；
- 预览中的 HTML、PPT、PDF 采用演示内容，不代表已经实现正式格式导出；
- 演示数据及状态不作为生产数据，勿上传敏感文件；
- 行政区划选项可能需要网络加载，离线时可手工输入。

## 后续开发约束

继续沿用 `pre-design` 的 Workspace、8 章 62 项研究目标（按开发进度实现）以及 Presentation Standard Project Directory 0.1.0，不在独立 Web 前端重建 Agent Harness。

正式架构计划为：Web 前端 → 受控项目/权限/任务服务 → DSH Harness + pre-design Skill → 服务器项目 Workspace。现有 `main` 的 DSH 插件代码不因本次原型提交发生改动。

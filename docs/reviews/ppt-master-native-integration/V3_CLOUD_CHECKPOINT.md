# V3 云端开发检查点

本轮在云端 `codex/web-v210` 接续；没有更改生产服务器、端口、数据库或部署。

## 可用代码路径

- 现有 V14 会话入口发送 `referencePipeline=native-v3`，可选品牌/风格/页面/整套设计、可读性优先/设计特征优先。旧 API 未指定时保留 V2 兼容，既有 V1/V2 绑定不自动升级。
- inventory/观察/Profile 之后，读取拥有者的已校验私有 SVG，生成严格 Design Spec，再逐原型调用原有 DSH worker。每次原型调用带该原型实际参考页图（最多6张），PPTX 另带对应真实平面 SVG；来源不足不伪造原件。
- 模型生成的装饰 SVG 经白名单规范化，再真实调用固定上游 `svg_quality_checker.py --json`，最后由平台确定性编译 V3。模型不能自己生成通过收执。
- V3 package 保留 Design Spec、匿名继承图、证据、组件、SVG 原型、内容槽、容量、编译器/渲染器和上游版本。严格拒绝证据改写、结构意图位置漂移、容量缩水/遗漏、危险 SVG。
- V08–V13 既有路径支持 V3，SVG 隔离为 `img` 背景，项目内容继续采用可编辑 HTML 槽。按容量选变体，内容超限明确拒绝。冻结版本、局部/人工覆盖、旧成果 HTML 不自动改变。
- Q05 人工对照门禁覆盖 V3；改动后的 hash/renderer/检查收执不匹配时旧确认失效。
- 文字修订保留来源、添加用户改动证据，并重新执行上游 SVG 检查。另存单页资源保留实际生效主题与真实容量，不复制项目正文和图片。

## 明确支持边界

此版本实现**纯装饰几何 SVG + 可编辑内容槽**，不是任意 SVG 或可编辑 PPTX 镜像。

SVG 支持白名单几何、分组、渐变和受限本地裁剪。脚本、外链、事件、CSS字符串、foreignObject、源文本、嵌入图片、任意命名空间和实体均拒绝。原件照片/文字/表格/图表必须转成实际项目内容槽，不能偷渡为原型内容。当前只声明 HTML，不声明已验收 PDF 或可编辑 PPTX 导出保真。

`masterLayoutGraph` 是基于证据生成的匿名设计结构，原件完整解析图保留在私有 Reference Bundle，不能把生成结构冒称无损原件复制。

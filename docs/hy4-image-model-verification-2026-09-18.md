## 本轮通用代码修正

1. `SessionImageCollector` 不再无限依赖下一条事件通知：使用一秒的可取消观察间隔，复查同一原子会话的内存/持久化状态。不会创建新执行或新模型请求，正常取消和真实订阅错误仍向上传递。已用漏接完成事件的测试复现旧问题，再验证图片、无图终结及空闲三条路径。
2. DSH 的 `toolFilter` 仅过滤继承工具，不能过滤子会话自己注册的工具。`preplanning-execution-guard` 根据可信持久化视觉委派描述，在工具执行体之前统一拦截视觉子会话的工具调用，包括再次委派；下个模型步骤开始前结束异常尝试。此规则适用于任何项目和任何生图模型，不依赖少潭河名称、任务 ID 或文件路径。
3. 视觉角色提示词同时明确禁止再委派、寻找其他模型和工具生图。执行拦截负责约束，提示词不替代程序限制。

等待状态修复已在真实测试中验证：子会话于 19:55:54.504 终结，上层执行于 19:55:56.864 收尾，相差 2.36 秒；首轮修复前则一直等到十分钟任务期限。

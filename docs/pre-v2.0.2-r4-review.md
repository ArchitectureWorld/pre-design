## 用户要求

- 模型卡片取消悬停上浮、倾斜、缩放，保留原有玻璃厚度、静态投影、A/B/C/D 配色与几何关系。动态光影仅限按钮。
- 保留已实现的 Klein＋独立必选配套 LLM 同排、图标化 `+`/排序/删除，以及窄屏同行布局。必填、不可用、配置冲突及读取失败仍可见。
- 执行记录改为独立原生模态窗口，最大 700 px / 80dvh，内部滚动，不推高主页面。按启动时间倒序展示已返回的当前项目全部记录，不截断为 20 条。旧任务的心跳更新不排到新任务前；保留启动/实际路由、配套 LLM、冻结备用链与错误详情，不把 idle 当完成。支持 Esc、关闭按钮、背景点击及关闭后焦点恢复。
- 外观中增加图片选择、替换和恢复默认。有效 JPEG / PNG / WebP，输入不超过 20 MB / 4800 万像素，等比规范化为最长边 2560 px 的静态位图，居中 cover，不拉伸。
- 背景仅保存在当前浏览器的独立 IndexedDB，不上传服务器、不写模型配置或项目附件。切换主题保留背景。存储受限时仍可临时使用并明确提示；坏文件不覆盖上次有效背景。处理替换/重置/恢复的异步竞争，释放位图和对象 URL。

## 下拉菜单问题

原 R2 的 5 秒轮询及 window.focus 读取共用 busy 状态，短暂 disabled 会关闭原生 select 菜单。分支 `2886547` 已修复：被动读取不锁定控件；选择期间暂停发起自动读取，已有在途结果/错误延后处理；保存与主动重载可抢占只读请求，过期返回不能覆盖新结果。本轮不改写该实现，增加联合浏览器验收证明新背景和弹窗功能未使其回归。真实窗口/标签切换可能自然关闭操作系统菜单；验收针对插件刷新不能打断用户正在进行的选择。

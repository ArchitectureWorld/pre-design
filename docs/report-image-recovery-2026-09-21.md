# 导出中断后的图片回收

同批生图有部分失败时，旧流程在处理成功结果之前抛出错误。图片文件虽已保存，成功结果却未进入本次审核、分配和采用，错误路径也未写出配图缺口。

本次修复将成功结果的入库、实际审图、分配和采用放在失败传播之前，仍等候所有已派发任务终结，失败后不启动下一批生图。中断记录包含尚未分配的位置和原始错误。正常图片质量、来源、裁切和复用上限检查保持执行。

续跑会按项目、Revision 和当前场景需求确定任务标识，从治理记录恢复已有合格候选。被拒收的图片不恢复；恢复本身不启动模型任务，也不直接批准或采用图片，仍由素材流水线核验。

`/preplan-export --reuse-images` 暂停本次导出的新生图请求，继续恢复历史图片、审核已有素材和获取网络素材。它不修改全局模型/备用模型设定、生图授权或模型任务额度；素材不足时仍拒绝发布，并给出缺口。普通 `/preplan-export` 保持原有按需生图行为。

验证：新增回归先复现“成功同伴未采用”、禁止新生图时未恢复候选和单次导出限制未传递。修复后相关测试通过。严格类型检查和构建通过；完整 191 个测试文件 1791 项通过、2 项可选本机驱动测试跳过，随后启用已安装 DSH 驱动的完整 25 项测试通过，覆盖这两项。

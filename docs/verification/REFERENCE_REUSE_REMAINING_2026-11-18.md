# 真实参考到可复用资产：当前交付与核心缺口

## 已贯通（准确区分证据）

新上传选择1–6页 → 来源验证 → 组件/可选语义观察 → Profile → 本地派生结构声明 → 组件适配 → 私有待审 → 原页对照与显式确认 → 真实项目原文映射/强调 → 几何检测 → 导出不含项目正文。

完整链已用真实浏览器/HTTP/PostgreSQL与受控模型响应验证；不是新一次真实供应商全链质量测试。已有真实第15页各阶段输出和候选证明部分能力，不等于三页或87页全自动通过。2026-11-18修复避免新图像型逐组件任务付费复制Profile；旧任务/PPTX原生路径未改，结构关系明确平台派生。

## 剩余关键步骤（按影响）

1. **真实模型结果稳定到可读几何**：观察覆盖与局部样式仍需人工核图，Profile/adapt仍可能拒绝。既有模型结果只在受控预算内继续验证；不得用一次schema通过推算成功率。
2. **传输预算进入一般工作流**：既有真实JPEG试验解决了单轮主路由输入体积问题并保存原/派生图身份；一般上传仍不能假称所有供应商/文件体积均受同一最终wire硬门禁。若推进，应版本化且不改旧缓存，不猜供应商上限，不能无授权降采样。
3. **精细设计保真**：纸纹、水印、书法、复杂装饰、源字体、颜色/强调边界缺失或派生；图像素材的复用授权独立于版式共享目的。不要复制受限PDF原生文字/素材来填补。
4. **多页整套质量**：分批上限与页覆盖标示已存在；跨页风格/章节规则及完整内容容量、表格图像与结构表辨别尚不能用单页通过代表。87页成本也未实测。
5. **可复用体验判断**：用户须在一个推荐既有候选上判断强调强弱、正文密度、三栏节奏；不再通过新增同名候选稀释反馈。显式内容适配可保留原稿，但不承诺任意长内容都能放进参考布局。

## 本轮非目标

不新增真实模型调用、不新增生产候选、不改用户已审版本、不对外发布；本地声明优化是可靠性/调用数改进，不是视觉质量跃升。真实费用未知，不标零成本。

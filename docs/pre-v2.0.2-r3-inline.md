## 接续与范围

继续 `pre-V2.0.2`，接续并行完成的 `6815bf70f1f01dc71acef25d79738a190fbe4693`，不覆盖其 R2 改进。核对 main 基准仍为 `801afcc794b34fa734ba624303ed9552b152407c`。

## 实现

- 主选项：同一个 `.route-pair` 内是生图工具、连接符、必填配套 LLM。普通生图 API 只有一个模型选择。
- 每个备用项：模型名称与其独立配套 LLM 并排，排序/删除图标在同排右侧。主/备用同样适用，320 px 窄窗口仍不把两模型拆成上下行。
- 添加保持单个 `+` 图标；完整可访问名称和悬停提示保留。上移、下移、删除、刷新、文件夹、外观继承 R2 图标化；保存/放弃修改仅在编辑后出现。
- 帮助按钮移到类别标题旁边，说明按需查看，不挤占模型选择宽度。移动端帮助弹层以类别行作为定位基准，保留上下自适应、滚动、Escape 和焦点恢复。
- 不修改 `glass-styles.ts`、`glass-optics.ts`、`glass-appearance.ts` 的既有材质/主题/图标比例，只增加 `glass-inline-styles.ts` 的布局覆盖；A/C、B/D 参数分别保持一致。

## 保留的并行修复与边界

`6815bf7` 中的工具身份过滤、同名模型区分、备用提升主选项时保留已显式配置的 LLM、执行记录中的启动/实际配套模型与冻结备用链全部保留。主选项和每个备用项仍分别保存自己的 LLM，不从其他类别或父会话推断。缺失/不可用配套、读取失败、冲突和保存失败仍显示，未隐藏错误。

地址、工作流、凭据仍在 DSH ComfyUI 插件中管理。本轮没有后端、调度、数据契约、SDK 或依赖变更。样式仅作用于 `.pre-glass`。

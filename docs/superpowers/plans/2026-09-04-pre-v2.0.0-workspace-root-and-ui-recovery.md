# Pre 2.0.0 Workspace Root and UI Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bind Pre 2.0.0 to the current DSH Workspace, publish the Presentation standard project directly in that Workspace root, preserve unrelated Workspace files, restore UI form drafts after refresh, and add an in-plugin open-folder action.

**Architecture:** `SessionHeader.cwd` is canonicalized with `realpath` and becomes the project root. `PresentationBindingRepository` owns the one-Workspace/one-Pre-project relation. A new Workspace Writer stages and validates Canonical output, swaps only Pre-managed paths, preserves `layouts/` and unrelated files, and rolls back on failure. Browser form state is persisted by Workspace path.

**Tech Stack:** TypeScript 5.9, Node.js 22, React 18, Vitest 3, DSH 0.1.1-rc.2, Presentation Contract 0.1.0.

**Spec:** `docs/superpowers/specs/2026-09-04-pre-v2.0.0-workspace-root-and-ui-recovery-design.md`

# 图块拖动与单页标题修正

**目标：** 右键拖动图块、单页不设条级标题、多页保留条级标题、上传图标向上。

**方案：** 沿用现有原型。右键命中图块时由独立拖动控制器接管，画布位置不变；坐标换算考虑缩放，拖动时连线随动、对齐线反馈，松开吸附网格/同级边线并避免重叠。保留父子连线的从左至右方向，布局保存在当前浏览器的项目/稿件作用域内，不改确认顺序或正文。空白画布维持现有平移操作。

单页节使用节编号和节标题，不重复增加条标题；多页保留条编号/标题。界面、HTML/Markdown 导出和新生成汇报页采用同一规则，底层 item ID 与一条一页关系不变。图块摘要显示正文，不显示 Markdown 标记。

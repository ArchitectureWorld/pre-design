# 子 Agent 类配置（已确认）

目标：仅提供生成图像、网络查询、文本生成三类；全局配置 DSH Provider/模型，所有前期策划项目共用，不随项目变化。执行记录按项目查看。配置只影响后续实例，不改写历史或正在运行的付费请求。

1. 增加独立 storage domain 和服务。目录复用 DSH `listProviders`、`listConfigurableProviders`、`listModels`；保存与派发均检查可用性。配置使用版本检查，执行记录保留派发快照，以子 Session 的 request/header 作为实际模型证据。
2. 文本分析、视觉生成接入统一路由与记录；视觉恢复保留原 route/runId，不重新付费。网络查询使用真实 spawn 子会话，仅开放 DSH web_search/web_fetch；只有实际成功工具记录才算查询成功，输出仍为待验证资料。
3. 提供检查同源的全局配置读写接口；无需创建项目即可配置，执行列表仅读取当前 Session 绑定项目。前期策划面板加入三类设置与执行列表。模型目录刷新不覆盖尚未保存的选择，保存检查全局版本。
4. 针对目录变化、保存重开、项目隔离、派发快照、真实模型/工具证据、视觉恢复、界面状态和接口身份编写测试，随后实现。运行类型检查、构建、相关测试及完整回归；原有 print-layout 基线失败单独列明。
5. 在隔离 DSH 和侧边浏览器验证，生成更新后的候选包与验收记录。正式安装/重启保留至候选验证后最后确认。

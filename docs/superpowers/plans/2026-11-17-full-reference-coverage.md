# 全文参考版式提取：分批覆盖与可恢复流程

用户目标是提炼可复用版式资产，不是生成 PPT；87页参考不能以3页代表验证冒称全文完成。既有架构仍为V14、同一私有上传记录、平台任务和权限、原生版式库。

## 实施顺序

1. PDF解析增加可选起始原页号，每批最多30页；保持原文件哈希、总页数、原页号及文字偏移，旧API默认不变。
2. 私有上传原件只存一次。逐批追加分页图和事实，事务行锁串行同源续读；哈希校验、拥有者限制、失败不更新覆盖；六图惰性读取而非一次加载87图。
3. 模型观察按最多6图执行，验证批次恰好覆盖输入。完成阶段以源哈希/图像哈希/请求/策略/技能版本绑定持久检查点，失败恢复不重复已确认付费阶段。未知完成状态不得当成功。
4. 分层设计摘要保留每个原页映射与原始事实引用；受限Profile综合使用有证据摘要，不截断丢弃页面。按原型显式选择代表图，区分全页观察与原型直接参考。
5. UI与收执分别显示提取、观察、综合、原型直接参考、失败待处理页。完成覆盖必须为所有原页都已观察且纳入综合，不能取提取数量代替。
6. 在隔离PG/浏览器测试并运行全部CI，随后对已授权瑶光路线做有预算的真实参考验证。备份并重查正式服务后才部署；原件不公开，共享仍须既有审核。

## 门禁与成本

87页为3个解析批、15个观察批；有必要时3个摘要批，再Profile/Spec及A个原型，预计20+A次，无供应商费用返回则只报请求/tokens。每阶段设限，异常停止诊断；不以无界重试换通过。

旧V1/V2/V3、旧64图整体加载API、人工确认和发布门禁保持兼容。真实技术完成与视觉评价分别记录，不声称小样本支持95%总体可靠性。

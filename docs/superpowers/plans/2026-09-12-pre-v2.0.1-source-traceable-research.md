# Pre 2.0.1 Source-Traceable Research Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a version-isolated Pre 2.0.1 research layer where each important fact and conclusion can be traced to a real source, normalized input, deterministic method, and analysis trace before it can receive trusted automatic quality status.

**Architecture:** `feat/pre-v2.0.1` remains isolated from the deployable `feat/pre-v2.0.0` runtime. A new `src/research/` subsystem loads versioned JSON research contracts from `research/v2.0.1/`, validates them, and exposes source/workflow lookup APIs. Later phases add providers and validators without changing the existing 57 State Object contracts.

**Tech Stack:** TypeScript 5.9, Node 24.11, AJV 2020-12, Vitest, DSH plugin runtime.

**Spec:** `docs/superpowers/specs/2026-09-12-pre-v2.0.1-source-traceable-research-design.md`

## Global Constraints

- All production changes go only to `feat/pre-v2.0.1`.
- `feat/pre-v2.0.0` remains the current deployable baseline.
- Pre package/product version becomes `2.0.1`; Presentation Project Format stays `0.1.0`.
- P5 inference/assumption can never be treated as standalone fact evidence.
- Deterministic calculations must not be fabricated by the LLM.
- Missing evidence must remain missing/unknown/blocked rather than becoming synthetic numbers.
- Runtime research files must be included in the packed npm package.

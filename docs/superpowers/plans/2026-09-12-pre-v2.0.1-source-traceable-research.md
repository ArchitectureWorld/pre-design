# Pre 2.0.1 Source-Traceable Research Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a version-isolated Pre 2.0.1 research layer where each important fact and conclusion can be traced through a real ResearchStep to a real source, normalized input, deterministic method, and analysis trace before it can receive trusted automatic quality status.

**Architecture:** `feat/pre-v2.0.1` evolves from the formal Pre V2.0.0 baseline `main@49140423e14f3d3abcf3815c9bdf68e8e5e26730`. The `src/research/` subsystem loads versioned JSON research contracts from `research/v2.0.1/`, validates source/workflow/step relations, and exposes provider/evidence APIs without changing the existing 57 State Object identities. The audit HTML is generated from these same contracts so the human review surface cannot drift from the machine-readable research chain.

**Tech Stack:** TypeScript 5.9, Node 24.11, AJV 2020-12, Vitest, DSH plugin runtime.

**Spec:** `docs/superpowers/specs/2026-09-12-pre-v2.0.1-source-traceable-research-design.md`

## Global Constraints

- All V2.0.1 production changes go only to `feat/pre-v2.0.1` until explicit merge approval.
- Formal V2.0.0 baseline is `main@49140423e14f3d3abcf3815c9bdf68e8e5e26730`; historical `feat/pre-v2.0.0` is not an active baseline.
- Pre package/product version is `2.0.1`; Presentation Project Format stays `0.1.0`.
- Research hierarchy is `Chapter → Workflow → ResearchStep → DataPoint → DataSource → EvidenceRecord → AnalysisTrace → OutputClaim`.
- P5 inference/assumption can never be treated as standalone fact evidence.
- Deterministic calculations must not be fabricated by the LLM.
- Missing evidence must remain missing/unknown/blocked rather than becoming synthetic numbers.
- Runtime research files must be included in the packed npm package.
- Unmapped Workflows must be reported as unmapped; they must not inherit a generic website list.

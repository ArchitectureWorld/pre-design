# 画布版式配置与统一会话工作台实施计划

> 执行时使用 superpowers:executing-plans，按任务逐项完成并验证。

**目标**　在页脚本阶段配置全局及局部版式，并以左侧成果、右侧上传与会话的工作台完成自定义。

**架构**　沿用现有版式资源、绑定、渲染和队列。页脚本使用原有稳定页面 ID。对话从任务记录组成持久历史，模型修订与资源版本原子保存。

**技术**　原生 JavaScript、Fastify、PostgreSQL、DSH、Playwright。

**设计依据**　[画布与会话调整](../specs/2026-11-14-visual-layout-bindings.md)。

## 约束与检查重点

固定 Web HTTP 4320 与 DSH HTTPS 3080。左侧成果、右侧文件和会话。人工属性覆盖优先于局部与全局。已有稿件、版式、任务记录和冻结成果继续可读。

关注未生成成果时的配置、双用户资源权限、并发版本冲突、刷新后的会话恢复，以及模型失败后的预览保留。

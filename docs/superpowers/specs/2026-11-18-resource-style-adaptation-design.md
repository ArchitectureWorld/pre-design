# 既有资源风格的内容适配版

## 目标与授权
父任务明确继续：基于既有资源风格重新设计，使真实少内容业务页能够直观预览与使用；不需要再等方案确认。此功能不是恢复原 PDF 分析，也不是提高原件保真。沿用 V14 主系统与现有 V3 编译/版本/预览/审核链。

## 路线
选择独立的“基于当前风格创建内容适配版”动作，来源是当前已保存资源 ID/version/hash；只使用安全的色彩、字体、画布与间距参数。不能复用旧观察的身份冒充新观察，不伪造 completed job。现有可信图像观察派生动作与门禁保持不变。
相比人工导入旧观察收执，此路线不宣称验证旧文件来源；相比直接填原25槽，不复制或虚构文案、图像。生成0至3项要点和纯段落的固定平台策略，明确不观察/推断原页卡片数和可选性。

## 版本与权限
仅资源所有者可操作，绑定当前版本与hash；新增同资源草稿版本，原版式/元数据/素材/权限保留，不自动发布、审核、申请共享或绑定项目。记录独立用户请求证据和私有派生收执（策略、源资源、输出hash），新增布局标“平台风格重设计”。不将原版的验证/视觉审核转移到新版。

## 约束
不外部模型调用、不新取素材；原文只经已有内容槽消费。新布局没有图片槽，不留破图。不支持的小画布或过多内容明确拒绝。只在现有编译器和包校验能保持旧资源完整时允许；若旧素材不能安全重编译则保留原资源并拒绝。

## 验收
单元：权限/过期hash/策略输入/幂等/旧内容字节不变/清晰来源标记/原可信分析门禁仍拒绝缺来源。UI：独立动作、明确确认、dirty拒绝、POST+GET锁与迟到响应保护。真实PG+Chrome：用授权现有业务页面与旧候选的私有副本验证，新版预览→选用→冻结HTML相同，原文完整，不伪造任务或跳过校验。结果不冒称原PDF视觉保真、完整项目成功率或PDF/PPTX导出。

## 独立审查补充：来源与对照不能混淆
user证据仅表用户请求，不表示用户确认所有设计事实或版权。新增布局必须明确其resource-style身份；旧profile观察保留但不得被展示为新布局的原页精确观察。现有referencePagesForLayout的designSystem fallback不能静默把新布局解释为原PDF复刻；实现需提供准确来源展示，不能以客户端可伪造标记跳过审核。若独立资源样例对照需要服务端来源收执，须校验收执及源版本；若保留上游PDF对照，则明确它仅是上游风格参考。旧版式原图审核依旧必需，缺原图不保证整个新版可发布。新增布局不得继承旧fidelityFeatures的已还原结论；风格使用实际生效theme/canvas，保留合法可读性派生关系。

## 首版修订边界
私有派生收执只覆盖精确创建版本；普通改名/编辑后不得默默回退成原PDF对照，也不得继承旧hash收执。本轮对缺精确收执的已声明风格适配布局明确拒绝并提示历史版本/既有成果保留，但当前修改版本不能重新审阅，旧布局审核不受影响。完整修订来源传播不在首版通过声明内。

# 真实参考版式工作台设计

## 授权与目标
用户已确认执行此前讨论路线。先解决 PDF 第 5/13/15 页的真实视觉特征及可复用性，再扩展整册。开发在云端；本地只读取必要数据、测试及部署到原 4320。不得把几何通过当成视觉合格，不覆盖已有资源和项目。

## 路线取舍
- 仅重排 UI：快，但不能解决失真，拒绝作为完整交付。
- 原页整图当模板：视觉相似但不可编辑，且混入业务文字/水印，拒绝。
- 组件化可编辑布局＋有来源的独立装饰资产＋版本化适配：采用。已有 V3 资源保持兼容，扩展能力须显式声明，不能伪造源文件原生结构。

## 分步可验收结果
1. 工作台：资源内真实版式缩略图矩阵，单击选择、双击/按钮/键盘放大；大预览显示精确 layoutId；助手高级选项折叠。缩略图来自当前版本实际 renderer，不使用 Aa 示意冒充。
2. 改进请求：复用主体批注编辑器、待提交队列及批量提交语义；版式需新增资源/版本/布局/组件锚点，不能冒充项目成果批注。保存批注不运行模型；显式提交绑定当前版本并生成新候选，冲突不自动应用，不清空未成功提交内容。
3. 真实设计：来源观察不可变，忠实提取与适配分离。明确每一视觉特征 preserved/approximated/unsupported 及可编辑性。优先版式局部标题、富文本强调、卡片、图组、表格结构；装饰资产必须授权、内联/受控引用、独立于业务内容。不能用全页背景掩盖未提取结构。
4. 评估：逐页列出纸纹/书法/章号/叶片、表格合并/图例、三栏卡片/彩色标题带/重点/结论等特征；原页与候选对照、可编辑内容替换、密度变化及权限/安全/溢出各自出具状态。未知与未实现保持未通过。

## 非目标与约束
不保证 PDF 恢复真正原生母版、原字体可分发或可编辑 PPTX；不复制水印/业务正文到通用模板。不自动发布共享。无明确预算不重复调用模型；先复用缓存与源结构。既有 Q05/Q07/Q08、版本/hash、权限、并发、恢复机制不弱化。所有重大视觉替代必须记录原因，不改原始事实。

## 用户澄清：统一可复用资产（2026-11-17）
参考稿提取与预设版式的最终用途一致：沉淀为本人或其他成员可重复使用的版式，统一进入现有版式库矩阵、可预览并替换内容。来源类型只是溯源区别，不形成另一套产品、另一套资源库或永久临时候选。未经用户共享授权的资产保持私有；经验收与用户确认共享后沿用现有成员可用路径。原件访问与版式共享权限仍分离。

### 可复用目标与素材授权的边界（用户再次明确，2026-11-17）
用户原话要点：参考稿提取的目的，是沉淀本人或他人可复用的版式，与预设进入同一版式库。这是产品目标，不代表每个具体素材已经获准共享。可复用结构、私人参考原件、抽出的装饰对象及原字体应分别记录来源、使用依据与共享范围；不能因“供其他人使用”的总目标而自动公开参考 PDF、完整裁切前图像、业务照片或字体。共享前保留既有逐项权利校验及用户确认。

## 从三页样本走向一般上传流程：现状与下一步（2026-11-17）
- 当前三页样本已经进入统一版式库，可真实预览、私有复用和显式内容映射；不是另一个产品。
- 三页样本的对象选择、源字体/间距测量、文字槽和表格列宽定位仍含人工制作。上传其他参考稿不会自动得到相同质量，不能将样本成功等同通用自动提取完成。
- 已有自动链：私有上传/逐页观察 → 证据关联 Profile → Design Spec → 原型 → 安全编译 → 几何/试排检查 → 用户原页对照确认。几何通过不代表视觉还原通过。
- 已有能力但尚未接入一般提取链：受控 PNG 装饰资产及软蒙版还原、独立 textBlocks 与富文本强调、逐特征 fidelityFeatures 展示。必须继续打通输入证据、模型输出契约、编译留存及验收，不能仅修改提示文字就宣称完成。
- 最先补契约一致性：Profile/Design Spec/原型提示必须完整描述局部文字及容量，角色 JSON Schema 必须约束绑定键；用确定性阶段 fixture 证明新能力能穿过整条链。旧阶段检查点需保持契约版本可重放，不能静默改变进行中的任务输入。
- 原生对象提取另行实现：服务端读取已核验的 PDF 对象/原生文本坐标，输出带 SHA、页码、对象号及证据类别的候选；模型只能引用候选标识，不能伪造哈希、对象号或内嵌图片。照片/扫描页不能冒称原生文字或合并单元格已恢复。
- 对象筛选默认私有：先区分装饰与业务内容，保留源值与适配值；没有具体权利依据的对象禁止共享。裁切仅改变显示，不能视作脱敏。
- 可复用验收应分别覆盖：新的同类参考文件、内容替换后完整保留、密度变化、映射移除还原、未知字体降级、表格真实合并关系、原件不随版式泄漏、用户明确共享后成员可用。样本无溢出仅算其中一项。

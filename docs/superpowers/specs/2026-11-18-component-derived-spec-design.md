# 逐组件派生结构声明

目标：降低真实参考→可复用链中无必要的付费失败，不将结构通过当视觉通过。现链 design-spec 要求模型逐字复制已校验 Profile，V3 adapt 不读取其组件样式/图。曾多次付费失败来自该复制阶段。

路线：新显式逐组件任务保存 referenceDerivedSpecVersion=1，V14 在没有源原生继承图时用纯函数生成逐页独立 master/layout/slide 和角色声明，调用正式 validateDesignSpec，保持 Profile 完全相同。每页独立 master 是平台派生组织，不表示源母版。声明不添加样式/原文/素材/权限。已有原生图的参考保留原设计分析路径，明确记录未启用派生的原因，避免覆盖 PPTX 继承。

备选：继续加模型提示/schema（已多轮，不消除无必要复制）；优化图片传输（独立问题，不能解决本阶段结构错误）。选确定性派生：仅减少冗余声明，不代替设计理解、观察、适配、视觉验收。

旧任务缺版本仍原流程；未知版本/不兼容在cache/model前拒绝；新任务重试保留版本。原观察/Profile/adapt模型输入与缓存不变，不使用受限PDF原生数据。结果仍私有待审，用户可见限制说明，实际执行收执 local stage 明示零模型。新输入估计说明一般少一阶段，源原生图仍可能需要设计阶段。

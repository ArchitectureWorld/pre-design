# 可交互章节流程与资料补充

用户明确指定：先根据资料推荐章节；用户拖动排序、移出或从未用章节区拖入；提交之后核对资料；缺少必要资料时询问，可明确跳过并在后续标注。另要求上传时筛出CAD，现阶段改为提供PDF或图像。

实现选择：沿用现有单页、玻璃卡片风格和工作台，在首轮卡片内增加可拖动的有序流程及备用章节区。保留按钮操作作为键盘/触屏替代。不引入另一套流程图库或改造全站。章节目录仍有11个标准模块，但本轮选择与顺序由用户决定，不能再强制全选或自动恢复标准顺序。

阶段：系统推荐 → 用户编辑（本地暂存，刷新保留）→ 提交到服务器、模型按指定顺序比对资料 → 用户补充/按问题跳过 → 明确确认当前版本 → 工作台按该顺序呈现。改序或加减章后必须重新提交核对，禁止沿用旧核对结果确认。服务器保存提交顺序，模型无权更改。先前的资料能力判断继续有效，跳过只是本轮接受缺口，不使未知资料变成已有事实，不解除专业成果的实际数据要求。

跳过记录包含问题原文、受影响章、理由、操作人、版本和时间。与当前版本绑定；刷新恢复，进入工作台仍可查看。后续生成包含这些限制说明。新资料使旧核对过期，需要重新比对。

上传：识别常见CAD扩展名并逐项显示替换清单，新上传接口拒绝CAD原件并提示PDF/PNG/JPEG/WebP。文件夹中其他资料继续使用；已存CAD原件保留且明确待补可读版本。新增补充资料入口用于当前项目，不要求重新建项目。

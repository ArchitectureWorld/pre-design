# 版式参考附件与会话输入框

用户要求把参考文件上传移到会话输入区，采用ChatGPT式的附件交互，完成后同步远程支线。现有左侧版式成果、右侧会话及页面视觉风格继续使用。

## 交互

- “参考文件”入口位于右侧输入框左下角，发送位于右下角。
- 待发送附件置于输入框内上方，紧凑横排；显示真实上传/解析进度，支持取消、移除及失败重试。
- 普通参考上传完成后等待用户发送，可以先补充文字；点击发送或按Enter提交，Shift+Enter换行。
- 已发送附件放在对应历史消息中，可下载原件；旧记录缺少消息归属时仍显示可下载的历史参考。
- 支持拖入文件和粘贴PNG/JPEG/WebP图片，拖入时突出输入框，粘贴普通文字保持正常。
- PDF100 MiB/前30页、现有格式、权限处理与模型配置均保持。原生JSON/PPTX导入继续走现有导入流程，不自动调用模型。

## 实现选择

仅把页头按钮移到底部虽可减少鼠标移动，但附件仍与待发送消息分离；本次把入口、待发送附件和输入区合并。已发送附件留在消息中，避免随着参考增多持续挤占输入区。使用原生DOM/CSS及既有上传接口，不增加组件库或后端接口。

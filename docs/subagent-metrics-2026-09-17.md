## 代码与适用范围

DSH 子会话列表从 Session summary 中读取 tokenUsage、subagentTiming、title。状态事件只更新 running；正常统计依赖另一条 projection control stream。现场证实列表停留在初始投影，重新读取权威列表可恢复。本轮没有捕获该流的网络丢失原因，不把推测写成已证明的上游根因。

前期策划客户端新增 `subagent-summary-sync.ts`，通过 DSH 公开的 `sessions.list` 和 `sessions.refresh()` API 校准：

- 发现子会话或运行状态变化时合并为一次刷新；
- 有运行中的子会话时每 15 秒校准；全部结束后停止轮询；
- 刷新在途时记录一次后续刷新，避免完成事件被旧请求吞掉；
- 抛出异常时最多额外重试两次，延迟 1 秒、2 秒；
- 插件卸载时解除订阅、清除计时器。

校准读取整个 DSH 子会话列表，以兼容原生列表的统一数据源，不修改 DSH 核心安装文件。不会打开或重跑子会话、调用模型、修改持久统计或改变模型路由。供应商未提供 usage 的会话仍可能显示 0；本修复不伪造用量，也不改变 DSH 原生的缺失用量展示文案。

## 验证

新增回归覆盖状态先到/投影漏更新、并发合批、在途完成竞态、无空闲循环、断网恢复、有限失败重试及卸载清理。部署和实际浏览器验收结果记录在当日监督日志及本地部署回执中。

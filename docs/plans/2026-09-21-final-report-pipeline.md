## 范围与不变量

- 开发目录 E:/前期策划开发，既有 feat/pre-v2.0.1 分支；保留原稿、来源、素材和执行记录。
- HTML、16:9 单页浏览；纯文字及表格页不超过 15%；原图含缩放裁剪最多两次、同页不得重复。
- 场景图保留主体及至少 80% 原图；真实地图保留分析信息、来源、方向、比例及图例。

## 任务和责任

1. 主任务：建立页面任务、稳定内容单元、来源映射；全稿论点与证据统筹；允许展示页合并/重排但保持可追溯和重要条件；语义重复审查不靠关键词直接删事实。
2. 布局任务：明确满版/半版/阵列/地图模板及可见像素约束；联合分页；回收尾句及稀疏续页；先产生稳定页面与图像槽，再补图。拥有 src/report/regular/** 及相关测试，主任务负责素材管线接入。
3. 地图任务：独立真实地图和分析资料管线，坐标系、路线/直线距离区别、可追溯节点和数据，缺项记录；场景图不得替代地域分析。拥有新地图分析模块和对应测试，不改全稿编辑和分页。
4. 主任务集成：稳定内容计划 → 稳定页面计划 → 场景/地图分别获取 → 原图去重与内容审查 → 原生 HTML 导出。旧补图结果按来源、哈希和需求兼容性复用。
5. 全分支验证和实际浏览器验收：不同项目、长短文案、横竖/方图、多图和地图；检查可见像素贴边、稀疏尾页、语义重复、地图事实/来源、纯文字占比和图片复用。发布并打开真实新 HTML。

## 集成接口

- 页面增加可选 task，含 kind、question、scale、requiredEvidence、preferredTemplate；旧稿通过统一页面任务规划生成该字段。
- task.kind 区分 scene、regional-context、accessibility、audience-catchment、competitor-distribution、site-analysis、process、comparison、financial、divider。
- 地图模块输出带证据、坐标系和来源的分析资产或明确缺项，不输出伪造底图或等时圈。
- 布局模块暴露稳定 imageSlots（使用位置 id、画框、目标比例、节点关联），最终新增图片不得触发额外续页需求。
- 主任务拥有 manuscript/types.ts、编辑/规划模块、visual-scenes.ts 和 presentation/report-image-pipeline.ts；跨职责文件先协调。
